# Documentação Técnica — Storm Aceleradora

Desenvolvido por: DevCraft — Soluções em Tecnologia (`http://devcraft.dev.br/`)

## Stack
- Vite, React, TypeScript
- Tailwind CSS, shadcn/ui
- Framer Motion
- React Router DOM

## Arquitetura
- src/components: componentes reutilizáveis
- src/pages: páginas (Index, SobreNos, NossasSolucoes, Metodologia, Cases)
- src/content/copy.ts: dicionário de textos centralizado
- public: arquivos estáticos (imagens, favicon, etc.)

## Funcionalidades
- Site estático otimizado para hospedagem
- Gestos touch, animações Framer Motion
- FAQ com acordeão e estado controlado
- Metodologia em 4 etapas com layout responsivo
- Footer consistente e centralizado por copy

## Build e Dev
- Desenvolvimento: `npm run dev`
- Build: `npm run build`
- Preview: `npm run preview`
